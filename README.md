# titanic/data_analysis_Matplotlib
Use Matplotlib library to visualization data
#Introduction 
This mini project used to visualization data
The goal is create charts (scatter , bar , boxplot , line , ...) used to analysis data
#Main file : train.csv
#Content
Read data from file train.csv 
Draw plot ( number of group sex , number of group pclass  , survival_rate of group embarked , Histogram used to distribute age data ....)
Use Scatter , Bar , Line , Histogram .... 
#Tools
Use Matplotlib to draw 
Use Pandas to read data
Use Pycharm (JupyterNotebook) to write code
#Result
The charts make it easy to view trends , distributions , relationship between variable in dataset
